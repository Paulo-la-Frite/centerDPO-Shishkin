# Информационная система учебного центра

Учебный проект по дисциплине «Разработка кода информационных систем».

## Описание проекта

Проект представляет собой информационную систему учебного центра дополнительного профессионального образования (ДПО).

Основная задача проекта — разработка Java-приложения для хранения и обработки информации:

* о студентах;
* преподавателях;
* образовательных программах;
* курсах учебного центра.

## Реализованный функционал

* Создание Maven-проекта
* Реализация объектно-ориентированной модели
* Работа с сущностями:

  * Person
  * Student
  * Teacher
  * Program
  * Course
* Консольное меню
* Работа с CSV-файлами
* Чтение и запись данных через File I/O
* Использование конструкции switch-case

## Используемые технологии

* Java 17
* Maven
* IntelliJ IDEA
* Git
* GitHub

## Структура проекта

* `src/main/java` — исходный код проекта
* `src/main/resources` — файлы ресурсов и CSV
* `pom.xml` — конфигурация Maven
