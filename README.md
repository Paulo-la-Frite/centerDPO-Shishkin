# centerDPO-Shishkin

Информационная система учебного центра.

Учебный проект по дисциплине:
«Разработка кода информационных систем».

## Возможности проекта

- Авторизация пользователей
- Разделение ролей:
    - Администратор центра
    - Гость
    - Администратор системы
- Графический интерфейс на Java Swing
- Формы добавления:
    - студентов
    - преподавателей
    - программ обучения
- Валидация пользовательского ввода
- Обработка событий и переходов между окнами

## Используемые технологии

- Java
- Swing
- Apache NetBeans
- MVC
